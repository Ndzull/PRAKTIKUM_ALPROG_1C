<h1>Bilangan dan String</h1>
<h2>Bilangan</h2>
Bilangan adalah tipe data yang digunakan untuk merepresentasikan nilai numerik. Dalam pemrograman, bilangan dapat dibagi menjadi beberapa jenis:<br>
- Integer (Bilangan Bulat)<br>
```>>> int_var = 10
>>> type(int_var)
<class 'int'>```
- Float (Bilangan Desimal)<br>
```>>> float_var = 3.14
>>> type(float_var)
<class 'float'>```
- Complex (Bilangan Kompleks)<br>
```>>> complex_var = 2 + 3j
>>> type(complex_var)
<class 'complex'>```
- Boolean (True/False)<br><br>
```>>> bool_var = True
>>> type(bool_var)
<class 'bool'>```
Adapun operator aritmatika untuk mengoperasikan bilangan-bilangan tersebut, seperti:<br>
- Penjumlahan (+)<br>
```>>> 10 + 5
15```
- Pengurangan (-)<br>
```>>> 10 - 5
5```
- Perkalian (*)<br>
```>>> 10 * 5
50```
- Pembagian (/)<br>
```>>> 10 / 5
2.0```
- Floor Division (//)<br>
```>>> 10 // 5
2```
- Modulus (%)<br>
```>>> 10 % 5
0```
- Pangkat (**) atau (pow())<br>
```>>> 10 ** 2
100```
```>>> pow(10, 2)
100```
- Akar kuadrat (**0.5) atau (sqrt())<br>
```>>> 16 ** 0.5
4.0```
```>>> import math
>>> math.sqrt(16)
4.0```
<b>Apa itu Variabel?</b><br>
Variabel adalah tempat untuk menyimpan data atau nilai. Variabel dapat diibaratkan sebagai "wadah" yang dapat menampung berbagai jenis data, termasuk bilangan dan string.
<b>Gimana cara menampilkannya di terminal?</b><br>
Bisa menggunakan fungsi print() untuk menampilkan bilangan-bilangan tersebut. <br><br>

<h2>String</h2>
String adalah tipe data yang digunakan untuk merepresentasikan teks. String dapat terdiri dari satu atau lebih karakter, termasuk huruf, angka, dan simbol. Dalam pemrograman, string biasanya didefinisikan dengan menggunakan tanda kutip tunggal (' ') atau tanda kutip ganda (" ").<br>
